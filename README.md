# 3D 7-Segment Digital Clock – Android App

An Android application developed with MIT App Inventor to control the [3D 7-Segment Digital Clock](https://github.com/leonvandenbeukel/3D-7-Segment-Digital-Clock) by Leon van den Beukel.

## Features

- Bluetooth connection via HC-05
- Synchronization of the clock's date and time
- Temperature and humidity display
- Stopwatch control
- Scoreboard mode
- RGB color selection
- Brightness adjustment
- Quick color selection
- Rainbow lighting mode

## Files

The `MIT-App-Inventor` folder contains:

- **AIA project:** the editable MIT App Inventor source project.
- **APK:** the compiled Android application.

## Installation

1. Download the APK from the `MIT-App-Inventor` folder.
2. Install it on a compatible Android device.
3. Pair the phone with the clock's HC-05 Bluetooth module.
4. Open the app and connect to the clock.

Android may require you to authorize installation from your chosen file manager or browser.

## Source Project

To inspect or modify the app, download the `.aia` file and import it into [MIT App Inventor](https://ai2.appinventor.mit.edu/).
